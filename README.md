# 📊 Small Business Cash Flow & Expense Dashboard

## 📖 Project Overview

This project is a professional Microsoft Excel dashboard designed to help small businesses monitor their income, expenses, cash flow, and overall financial performance.

The dashboard provides interactive reports using Pivot Tables, Pivot Charts, KPI Cards, and Slicers, making financial analysis quick and user-friendly.

---

## ✨ Features

- 📈 Interactive Dashboard
- 💰 Income Tracking
- 💸 Expense Tracking
- 📊 Cash Flow Analysis
- 📌 KPI Cards
- 📉 Pivot Charts
- 📋 Pivot Tables
- 🎯 Slicers for Interactive Filtering
- ✅ Automated Calculations
- 📅 Monthly Financial Reports
